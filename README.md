# محمد يوسف الأحيدب - Portfolio Website 🇸🇦

موقع portfolio احترافي عالمي المستوى لمحمد يوسف الأحيدب - مبني بـ HTML/CSS/JavaScript النقي.

## 🚀 التشغيل المحلي

### الطريقة 1: باستخدام Python (الأسهل)
```bash
cd portfolio-html
python3 -m http.server 8000
```
ثم افتح: http://localhost:8000

### الطريقة 2: باستخدام VS Code Live Server
1. افتح المشروع في VS Code
2. انقر بزر الماوس الأيمن على `index.html`
3. اختر "Open with Live Server"

### الطريقة 3: مباشرة في المتصفح
افتح ملف `index.html` مباشرة في أي متصفح

## 📁 البنية

```
portfolio-html/
├── index.html          # الصفحة الرئيسية
├── css/

```
